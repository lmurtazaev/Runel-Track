# Таймер для учёта времени прямо в карточке задачи. 

Запускает и останавливает отсчёт одним нажатием, сохраняет затраченное время в ворклоги Трекера и помогает контролировать длительность работы над задачей.

## Какие задачи решает

- Упрощает учёт времени: не нужно переключаться между Трекером и внешними таймерами
- Показывает accumulate время по задаче — сколько потрачено суммарно
- Фиксирует каждую сессию отдельно, чтобы видеть динамику работы

## Возможности

- Запуск и остановка таймера одной кнопкой в карточке задачи или в боковой панели задачи
- Автоматическая запись затраченного времени в ворклоги
- Отображение суммарного времени по всем задачам и каждой задаче в отдельности во встроенном в плагин отчете по времени
- История сессий с датой и длительностью
- Поддержка нескольких одновременных таймеров для разных задач
- Сохранение состояния таймера (накопленного времени) после закрытия вкладки или перезагрузки браузера

## Для кого

- Разработчики, аналитики и тестировщики, которые ведут учёт времени в Трекере
- Руководители команд, которым важна прозрачность трудозатрат
- Любые специалисты, работающие по времени с оплачиваемыми ворклогами

## Как использовать

1. Откройте карточку задачи в Трекере
2. Нажмите кнопку запуска таймера в блоке плагина
3. Работайте над задачей — таймер отсчитывает время в фоне
4. По завершении нажмите кнопку остановки
5. Затраченное время автоматически запишется в ворклог задачи

Плагин встраивается в карточку задачи и не требует дополнительной настройки после установки.
