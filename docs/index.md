# ВоркТаймер

ВоркТаймер — плагин для учёта времени в карточке задачи Трекера. Запускает таймер одним нажатием и автоматически записывает затраченное время в ворклоги.

## Возможности

- Запуск и остановка таймера в карточке задачи
- Автоматическая запись времени в ворклоги при остановке
- Отображение суммарного времени по задаче
- История сессий с датой и длительностью
- Поддержка одновременных таймеров для разных задач
- Возможность просматривать отчет о затраченном времени на задачи с фильтрацией по дате
- Ручное создание ворклога (добавление времени к задаче)

## Установка

Плагин устанавливается администратором организации из каталога плагинов Трекера. После установки дополнительная настройка не требуется — таймер появляется в карточке задачи автоматически. Также плагин доступен в навигационной панели Трекера.

## Использование

1. Откройте карточку задачи в Трекере или в боковой панели
2. В блоке плагина нажмите «Старт»
3. Работайте над задачей — таймер отсчитывает время в фоне
4. По завершении нажмите «Стоп»
5. Время автоматически запишется в ворклог задачи
6. Для вывода отчета о затраченном времени на задачи за нужный период перейдите в навигационную панель, откройте плагин и переключитесь на вкладку "Отчеты"

## Частые вопросы

### Где в Трекере можно запустить таймер?

- В карточке задачи
- В боковой панели с деталями задачи
- В навигационной панели Трекера на странице плагина

### Можно ли запустить несколько таймеров одновременно?

Да. Каждый таймер привязан к своей задаче, поэтому можно вести несколько параллельно.

### Что произойдёт, если закрыть браузер?

Таймер восстановится, даже если он не был поставлен на паузу, и отобразит актуальное накопленное количество времени.

### Кто видит записанное время?

Ворклоги видны всем участникам задачи согласно правам доступа в Трекере.

### Можно ли просматривать отчеты по времени, затраченному на задачи?

Да. Перейдите на страницу плагина из навигационной панели Трекера и откройте вкладку "Отчеты". Там отобразится отчет по трудозатратам, который можно отфильтровать по дате и очереди. Отчет можно просматривать как в виде таблицы, так и в виде списка. 
Также есть возможность отображать и скрывать комментарии к ворклогам.

### Используемые разрешения

- `tracker:issues:read` используется для чтения задач.
- `tracker:issues:write` необходимо для создания записей о затраченном времени (worklog) в задачах Яндекс Трекера при выполнении метода  API `POST /v3/issues/{issue}/worklog` для автоматической регистрации времени после завершения работы таймера.
- `tracker:worklog:read` используется для чтения информации о затраченном на задачи времени.
- `tracker:worklog:write` используется записи информации о затраченном на задачи времени.
